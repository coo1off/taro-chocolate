# Таро Шоколад

**Живая версия:** [coo1off.github.io/taro-chocolate](https://coo1off.github.io/taro-chocolate/)

Атмосферный статичный сайт для раскладов Таро, рефлексии и знакомства с собой. Без сервера, без аккаунтов и без искусственного интеллекта: JavaScript перемешивает колоду из 78 карт, случайно выбирает карты, определяет перевёрнутые положения и собирает результат из заранее написанных текстов.

## Быстрый запуск

Сайт не требует сборки — это обычные HTML, CSS и JavaScript.

```bash
# из папки проекта
python3 -m http.server 8000
```

Откройте [http://localhost:8000](http://localhost:8000). Можно открыть и просто `index.html`, но локальный сервер надёжнее для шрифтов и `localStorage`.

## Что внутри

- **78 карт Райдера–Уэйта** — 22 старших и 56 младших арканов. Для каждой карты: прямое и перевёрнутое значение, любовь, деньги, работа, совет, ответ «да / нет», теневая сторона, ресурс и вопрос для рефлексии.
- **11 раскладов** — карта дня, быстрый расклад, прошлое/настоящее/будущее, отношения, деньги, работа, да/нет (1 и 3 карты), большой расклад на 7 карт, выбор, самопознание.
- **Анимация колоды** — перемешивание, раздача рубашкой вверх, переворот карт, открытие по одной или всех сразу.
- **Матрица судьбы** — расчёт по полной дате рождения: личный аркан, эмоции, род, зона комфорта, центр, линия любви, линия денег, баланс, кармический хвост и возрастные точки 20/40/60.
- **Каталог карт** — поиск и фильтры по старшим арканам и мастям, подробная карточка карты в модальном окне.
- **История** — последние 40 раскладов хранятся локально в `localStorage`; можно открыть, повторить или удалить.
- **Копирование и шеринг** — текст расклада копируется в буфер или передаётся через Web Share API.
- **Адаптивность** — от 320 px до широких экранов, поддержка `prefers-reduced-motion`.
- **Этика** — дисклеймер, раздел о приватности, FAQ на 15 вопросов, отсутствие запугивания и гарантий.

## Структура

```
index.html                  — оболочка SPA и подключение скриптов
assets/css/style.css        — дизайн-система и адаптивность
assets/js/app.js            — роутер, расклады, каталог, матрица, история
assets/js/card-art.js       — векторная графика всех карт (SVG, без внешних изображений)
assets/js/data/cards.js     — сгенерированная база 78 карт
assets/js/data/spreads.js   — расклады, позиции и шаблоны
assets/js/data/matrix.js    — 22 аркана матрицы и описания точек
assets/js/data/ui.js        — FAQ и принципы
src/content/*.json          — исходные тексты карт и матрицы
scripts/build-content.mjs   — сборка JSON в браузерные data-файлы
```

### Пересобрать контент

Если вы правите JSON в `src/content/`, пересоберите браузерные файлы:

```bash
node scripts/build-content.mjs
```

Скрипт проверяет структуру, количество карт (78), количество арканов матрицы (22), уникальность `id` и допустимые ответы «да / нет», затем записывает `assets/js/data/cards.js` и `assets/js/data/matrix.js`.

## Методика матрицы

Используется одна прозрачная схема, описанная на самой странице:

- `A` — день рождения, сведённый к 1–22;
- `B` — номер месяца;
- `C` — сумма цифр года, сведённая к 1–22;
- `D = A + B + C`, сведённое к 1–22;
- `E = A + B + C + D` — центр;
- линия любви `B + E`, линия денег `C + E`, баланс `любовь + деньги`, кармический хвост `A + C`;
- возрастные точки `E + 20`, `E + 40`, `E + 60`;
- число `22` соответствует Шуту.

Матрица судьбы — нумерологическая интерпретация, а не научно доказанный метод прогнозирования. Все формулировки на сайте поданы как темы для размышления.

## Приватность

Имя, дата рождения и вопрос обрабатываются только в браузере и не отправляются на сервер. История раскладов хранится в `localStorage` и удаляется кнопкой «Очистить историю» или очисткой данных сайта.

Единственный внешний запрос — шрифты Google Fonts. Без сети сайт остаётся рабочим и читаемым за счёт системных шрифтов.
